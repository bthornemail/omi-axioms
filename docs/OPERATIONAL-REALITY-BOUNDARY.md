# Operational Reality Boundary

## What Consensus Does and Does Not Determine

### 1. Three Reality Layers

The system distinguishes three layers of reality:

| Layer | Definition | Invariant |
|-------|------------|-----------|
| **Physical reality** | what is true regardless of belief | invariant under disagreement |
| **Operational reality** | what coordinated agents enact together | enacted by consensus |
| **Epistemic reality** | what an individual experiences/models | subjective, fallible |

### 2. The Boundaries Between Layers

```
Physical reality ──(invariant)──→ cannot be changed by consensus
     ↓
Operational reality ──(enacted)──→ structured by consensus, constrained by physics
     ↓
Epistemic reality ──(experienced)──→ individual model, may be wrong
```

The critical operational boundary:

**Consensus does not create physical truth.**
**Consensus structures operational reality.**
**Operational reality remains constrained by physical reality.**

### 3. How This Applies to OMI

| OMI component | Reality layer |
|---------------|---------------|
| Proof canonization | defines admissible structure (physical/formal) |
| Validation | determines accepted state (operational) |
| Attestation | witnesses accepted transitions (operational) |
| Projection | displays accepted state (epistemic/operational) |
| Individual observation | epistemic |

Validation operates at the **operational reality** layer. It does not create physical truth. It coordinates what agents agree to treat as accepted state.

### 4. Failure Is the Final Interrupt

No consensus, no validation, and no proof can override physical failure.

When a constraint is hit:

```
Physical reality interrupts.
Operational reality must adapt.
Epistemic reality must update.
```

This is built into the proof suite boundary:

```
Proof canonizes admissible structure.
Validation determines accepted state.
Attestation witnesses accepted transitions.
Projection displays accepted state.
Failure interrupts all of the above.
```

### 5. Consensus Coordinates — It Does Not Determine Truth

Consensus answers:

```
What do we agree to treat as true for operational purposes?
```

Consensus does **not** answer:

```
What is actually true independent of agreement?
```

The system only needs the first question answered. The second is not its job.

### 6. Relationship to the Proof Suite

```
Proof tells us what structures are admissible.
Consensus tells us which admissible structures are currently accepted.
Validation checks whether a candidate relation satisfies the admissible boundary.
Attestation records that a validation occurred.
Projection shows the result.
```

Each layer is independent. Proof is not consensus. Consensus is not proof. Validation is not projection.

### 7. Lock Statement

```
Physical reality is invariant under disagreement.
Operational reality is enacted by coordinated agents.
Epistemic reality is experienced and fallible.
Consensus coordinates action but does not determine truth.
Failure is the final interrupt.
```
