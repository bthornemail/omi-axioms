## Abstract

Base-36 sub-context ignores the standards and syntax literals.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**Base 36 is the largest case-insensitive alphanumeric radix**

1. 36 symbols
2. exactly 36 in the 36-block

**Every standard radix is a sub-plane of base 36**

3. ${name} value ${v} in base 36

**The standard prefix syntax is a parser hint (the cover)**

4. ${src} = 31
5. 0x1F = 0b11111
6. 0b11111 = 0o37
7. 0o37 = 31

**The base-36 sub-context ignores the prefix**

8. 31 in base 36 = v
9. uppercase V
10. V is at position 31
11. V in base 36 = 31

**The base-36 block contains all of 0-9 and A-F**

12. hex digit ${c} is in base 36
13. decimal digit ${c} is in base 36

**The base-36 sub-context covers the entire alphanumeric plane**

14. 36 values
15. 0 -> 0
16. 9 -> 9
17. A -> 10
18. Z -> 35

**The uncovered structure**

19. uncovered: ${claim}

**The base-36 case-insensitivity**

20. ${upper}/${lower} same value in base 36

**The prefix is unnecessary in base 36**

21. ${literal} -> "${b36}"
22. "${b36}" -> ${literal}

**The base-36 sub-context as an "uncovering"**

23. 36 = the block size
24. A = 10
25. Z = 35
