## Abstract

The compare-exchange is a predicate — CDL2's four rule types, run on a shared buffer.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**Test: can fail, no side effect (P1)**

1. the check fails on 0x0102 (density 2)
2. and never changes the buffer

**Predicate: changes the buffer only on success (P2)**

3. compareExchange fails when the cell is not the expected value
4. and then the buffer is byte-identical
5. it succeeds when the cell is the expected value
6. and then exactly that one cell changes

**Function: never fails, no side effect (P3)**

7. load never fails
8. and never changes the buffer

**Action: never fails, writes its cell (P4)**

9. store never fails
10. and changes exactly the cell it writes

**The four cells of the 2 x 2, each once (P5)**

11. the observed flags are CDL2's four cells
12. each cell once

**The exchange law on a 128-byte frame (P6)**

13. frame ${f}: the exchange finds 127
14. frame ${f}: only byte 60 ^ frame changes
15. frame ${f}: applied again it fails
16. frame ${f}: and changes nothing

**The kernel's two conditions over every 16-bit value (P7)**

17. odd texture never occurs: a closed loop of 16 bits flips an even number of times
18. even texture with density 8: every value with 8 bits set
19. C(16, 8)
