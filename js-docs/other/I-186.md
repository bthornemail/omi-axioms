## Abstract

The ASCII indices pass through UTF-8 as themselves.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):

1. every Unicode scalar value
2. 19 and 63 are themselves
3. and read back as themselves

## Carriers

The check as one classic script (types stripped; the host supplies `assert`, and `os` or `process` where used), in two base64 dialects that decode to the same bytes:

## Notes

- What it checks: over all 1,112,064 Unicode scalar values, UTF-8 writes each code point below 0x80 as its own byte and every other code point with bytes of 0x80 and above; 19 and 63 encode and decode as themselves.
- What it does not check: the history of the ASCII table (its 1963 edition left lowercase unassigned; the 1967 revision is the table later specs reference), or specs that do not use UTF-8.
