## Abstract

Polytron is a polynomial automaton.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**A^8 = 1, and no smaller power**

1. A^8 = 1
2. A^1 .. A^7 are not 1

**Eight steps return every word, for every constant**

3. 1 + A + ... + A^7 = 0, so K^8(p) = A^8 p + (1 + ... + A^7) C = p

## Notes

- What it checks: K(p, C) equals (x + x^3 + x^14) p + C over GF(2)[x]/(x^16 + 1) for all 65,536 words with C = 0x1D and 0x1D1D; A^8 = 1 and no smaller power; 1 + A + ... + A^7 = 0, so eight steps return every word for every C.
- Period exactly 8 for every word holds for 0x1D (I-195), not for every C: under 0x1D1D some words return sooner.
