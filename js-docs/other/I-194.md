## Abstract

The exceptional Lie algebras, named by /A-Z0-9/ tags, built from their simple roots.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**The name is a tag: family x 36 + rank**

1. ${name} is an /A-Z0-9/ tag
2. ${name} = family x 36 + rank
3. ${name}: ${rank} simple roots, the digit of its name

**The root system, built**

4. ${name}: ${k.roots} roots
5. ${name}: every root returns after ${k.h} Coxeter steps
6. ${name}: roots = rank x Coxeter number
7. ${name}: dimension ${k.dim} = roots + rank
8. E6, E7, E8 = I-510, I-511, I-512 = 2^9 - 2, 2^9 - 1, 2^9
9. E7 = 511 = 7 x 73

## Notes

- What it checks: each of G2, F4, E6, E7, E8 read as a base-36 tag is family x 36 + rank; its root system built from its simple roots by reflection has the known number of roots; its Coxeter element returns every root after the Coxeter number of steps; roots = rank x Coxeter number and dimension = roots + rank; E6, E7, E8 are 2^9 - 2, 2^9 - 1, 2^9.
- The archived Racket modules (~/devops/Vault/Archive/epistemic-observability-engine/substrate-geometry) were tried first: e8.rkt agrees; g2.rkt does not compile (an unbound coords), and f4.rkt and e6.rkt cannot load (f4.rkt and weyl.rkt require each other). The archive is unchanged.
