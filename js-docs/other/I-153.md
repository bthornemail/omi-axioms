## Abstract

Every deviation is a measurable boot difference.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**No deviation = no difference**

1. identical boots: no difference

**Every deviation produces at least one measurable difference**

2. "${d.name}" produces a measurable difference
3. "${d.name}" differs on ${expected}
4. 8 deviations tested

**The falsification condition**

5. "${d.name}" is falsifiable

**The deviation is measurable FROM boot**

6. boot time differs between boot and later

**Every boot trace is reproducible**

7. two identical boots produce identical traces

**The POST beep is the first measurable signal**

8. POST first
9. BEEP is the first measurable signal
10. USER_CODE last

**The anchor at index 60 is boot-stable**

11. anchor stable across writes

**The measurable quantities map to the vault**

12. 8 quantities mapped

**If a deviation is unmeasurable, the claim is invalid**

13. "${d.name}" IS measurable

**The protocol is falsifiable**

14. the null deviation produces no diff
15. real deviation "${d.name}" produces diff
