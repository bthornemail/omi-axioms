## Abstract

The delineation rule — the 2-of-5 encoding, tap code to.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**The 2-of-5 code**

1. C(5,2) = 10
2. `assert.deepEqual(valid25, [3, 5, 6, 9, 10, 12, 17, 18, 20, 24]);`
3. 20 = 0b10100, two bits set
4. `assert.equal(20, 0b10100);`
5. `assert.ok(valid25.includes(20));`

**20 5 is the boot**

6. `assert.equal(20, 0b10100);`
7. `assert.equal(5, 5);`
8. `assert.equal(/^[A-Z0-9]{1,8}$/.test("20"), true);`
9. `assert.equal(/^[A-Z0-9]{1,8}$/.test("5"), true);`

**The tap code**

10. `assert.equal(5 * 5, 25);`

**The usable stream**

11. `assert.equal(/^[A-Z0-9]{1,8}$/.test("20F5"), true);`
12. `assert.equal("20F5".length, 4);`
13. `assert.equal(parseInt("20F5", 16), 0x20f5);`
14. `assert.equal(0x20f5, 8437);`
