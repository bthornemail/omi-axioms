## Abstract

3! overlay (streams, GED).

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):

1. `assert.strictEqual(stdin.fd, 0);`
2. `assert.strictEqual(stdout.fd, 1);`
3. `assert.strictEqual(stderr.fd, 2);`
4. `assert.strictEqual(perms([0,1,2]).length, 6);`

## Notes

- Its three stream checks (stdin, stdout, stderr are fds 0, 1, 2) run asynchronously. In the roll-up they finish after the record is already marked passed, so there they do not gate it; only the 3! ordering count does. The vm carrier waits for them, so there they count.
- Those stream checks hold on a main thread; in a Worker the streams are not fds 0, 1, 2, so its Worker carrier fails on them.
