## Abstract

The gap as constant tag; beep content-specific for base-36.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**The structural reset: any 7-slot window**

1. window 0-6 closes
2. window 1-7 closes
3. window 4-10 does not close (only 6 left)

**The content-specific beep: base-36 literals**

4. gap char 0x${c.toString(16)} is NOT base-36
5. digit ${c} is base-36
6. letter ${c} is base-36

**The gap is the constant tag literal point**

7. gap starts right after digits
8. gap ends right before letters
9. gap = letterStart - digitEnd - 1
10. gap = 7 chars

**The tag is DOF-invariant**

11. gap same for ${dof} DOF

**The 6 DOF of the base-36 block**

12. 6 DOF

**6 DOF + 1 tag = 7**

13. @ = 0x40
14. gap length = DOF + 1
15. 6 + 1 = 7

**The beep fires for base-36 sequences, not for the gap**

16. base-36 sequence beeps
17. gap does NOT beep
18. mixed does not beep
19. all letters beeps

**For other DOF counts, the tag remains**

20. 6 DOF base-36 beeps
21. 4 DOF base-36 does not beep (different condition)

**The constant across ASCII and Unicode**

22. position ${i}: ASCII 0x${asciiGap[i].toString(16)} = Unicode 0x${unicodeBmpGap[i].toString(16)}

**The tag as the fixed point**

23. gap starts after digit block
24. gap ends before letter block
25. gap width = 7
