## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**The four groups**

1. :; = 2
2. <=>? = 4
3. {|}~ = 4
4. ` = 0x60

**The backtick is between _ and a**

5. _ = 0x5F
6. ` = 0x60
7. a = 0x61
8. ` = _ + 1
9. ` + 1 = a

**Case-flip = 0x20**

10. ${upper} -> ${lower} = 0x20
11. space = 0x20 = 32
12. last non-printing = 0x1F
13. first printing = 0x20

**The print boundary**

14. 0x1F non-printing
15. 0x20 printing (space)
16. 0x7E printing (~)
17. 0x7F non-printing (DEL)

**ESC and BOM as frame-switch markers**

18. ESC = 0x1B = 27
19. BOM BE = 0xFEFF
20. BOM LE = 0xFFFE
21. BOM BE and LE are byte swaps (swap16)
22. BOM BE ⊕ LE = 0x0101: each byte flips its low bit

**The C0/C1 mirror**

23. C0 ${c} -> C1 ${c1}

**The {|}~ / <=>? mirror**

24. brace - compare = 0x3F
25. ~ - ? = 0x3F
26. offset = 63 = '?'
27. upper mirror of ` = 0x9F

**Base-36 subscripts**

28. 36 base-36 digits
29. ${g} has ${variants} variants

**Tagged template literal**

30. cooked strings
31. interpolated values
32. TemplateLiteralArray

**Proxy/Catch (trap) vs Reflect/RegExp (default)**

33. proxy get -> Reflect.get
34. proxy get -> Reflect.get
35. catch handles the throw
36. RegExp literal matches
37. RegExp source

**COBS and 0x00**

38. COBS removes interior zeros
39. COBS adds framing bytes

**The Extended ASCII proxy boundary at 0x80**

40. DEL = last of ASCII
41. first of Extended ASCII / C1
42. 0x80 - ` = 0x20 (print boundary)
