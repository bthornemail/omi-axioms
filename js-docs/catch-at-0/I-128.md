## Abstract

Prompt characters + Atomics cycle + mod-12 chain.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**All prompt bytes are in the 36-block or control**

1. byte 0x${b.toString(16)} is in a known band

**Mod-12 reductions of the indices**

2. 60 mod 12 = 0
3. 128 mod 12 = 8
4. 64 mod 12 = 4

**The compare-exchange cycle at those indices**

5. swap 1 read index 60
6. swap 1 wrote index 60
7. swap 2 read index 128
8. swap 2 wrote index 128
9. swap 3 read index 64
10. swap 3 wrote index 64
11. final: 60 holds old 128
12. final: 128 holds old 64
13. final: 64 holds old 60

**The E % 0 hinge: NaN coerces to index 0**

14. E % 0 = NaN
15. E % 0 lands at index 0

**The Unicode / control-plane bands of the prompt**

16. ESC is C0 control 0x1B
17. '[' after ESC
18. prompt has control codes

**Uname output is pure printable ASCII**

19. uname byte 0x${b.toString(16)} printable

**The 0..64..128 range in the mod 0..12 frame**

20. chain 0/64/128 -> 0/4/8
21. the mod-12 set {0,4,8}
