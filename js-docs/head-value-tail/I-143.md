## Abstract

Prompt sigils as the two privilege frames.

## Statement

The check holds when each of the following holds, in this order (taken from its assertions):


**The node space 65536 = 2^16**

1. node = 2^16
2. node = 16^4

**The global space 65536^4 = 2^64**

3. global = 2^64
4. global = 16^16

**The three prompt exponents**

5. 16^19 = 2^76
6. 16^20 = 2^80
7. 16^21 = 2^84
8. 16^20 / 16^19 = 16
9. 16^21 / 16^20 = 16
10. 16^21 / 16^19 = 256 = 16^2

**The Unicode codepoint max is 21 bits**

11. 0x10FFFF is 21 bits
12. 0x10FFFF = 1114111
13. Unicode max = user exponent

**The fold 10^k -> 16^k = 2^(4k)**

14. 16^${k} = 2^${4*k}
15. 16^20 = 2^80

**Root is closer to 0**

16. root < mid < user
17. catch is below root
18. outer = root = 2^76
19. inner = user = 2^84

**The # and $ prompt semantics**

20. root
21. user
22. `assert.strictEqual(prompts["#"].bits, 76n);`
23. `assert.strictEqual(prompts["$"].bits, 84n);`
24. offset = 8 bits

**The 65536^4 space and its relation to the prompt space**

25. global = 16^16
26. root exp > 16 (global exp)
27. user exp > 16
28. root is 3 exponents above global

**The 10-folds-16 in each**

29. 20 folds
30. 20 folds -> 2^80

**The superuser/user asymmetry**

31. root is closer to 0 than user
32. user is 256x further from the catch
