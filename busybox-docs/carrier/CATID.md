# CATID — cat is a byte identity

- **status:** P1
- **category:** carrier
- **applets:** cat, cmp, wc, tr
- **owner:** `busybox/catalog/B-CATID.sh`
- **result:** holds

## Claim

cat reproduces its input byte-for-byte (cat < F equals F), and cat F F is exactly twice the bytes of F — cat is the identity carrier the switches ride on.

## Statements

- cat < F equals F, byte for byte
- cat F F is exactly twice the size
