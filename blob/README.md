# The proof Blob

One 65,536-bit index (8,192 bytes, byte j = 60 ⊕ (j & 0xFF)), stored as:

| File | Form |
|------|------|
| `proof.bin` | the raw bytes |
| `proof.0x`, `proof.0b`, `proof.0o`, `proof.0d` | the whole Blob as one literal in base 16, 2, 8, 10 |
| `proof.b32` | base32 (RFC 4648 alphabet A-Z2-7, no padding) |
| `proof.template.mjs` | a base32 tagged template literal; its default export is the bytes |

Every form XORs the Blob to 0n and 0u. Check it: `java Equivalence.java`.

**Do not `cat proof.bin` to a terminal.** One byte in eight is a terminal control code: 60 ⊕ 59 = 7 is BEL, so the bell rings 32 times, and 32 ESC bytes (0x1B) can scramble the terminal. View it with `xxd proof.bin | head`.
